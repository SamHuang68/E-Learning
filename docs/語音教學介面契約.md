# 語音教學介面契約 — voice-teaching.1

本契約為開發與審查資料，不匯入瀏覽器產物。

## 範圍與觀點

- 範圍：既有日語、英語與臺灣華語的主要教材及情境學習入口。
- 作者與維護者：Sam 的 E-Learning 專案；未指定外部贊助者。
- 內容型態：中立教學；教材主張與文字取自目前課程資料，不新增學習效果、真人錄音或發音評分主張。
- 使用者：需要原文示範、解說與跟讀的語言學習者。
- 責任：應用程式提供控制及教材串接；裝置／瀏覽器提供系統聲音。系統聲音可能使用遠端服務，不能概稱全部離線。
- 完成與後續操作由 Sam 決定；本輪不包含推送、部署或新雲端供應商。

## Direction contract

### THESIS

在既有教材旁提供可控制的「原文示範、解說、留白跟讀」，保留完整文字。教學順序取代裝飾性音訊入口；播放不自動增加學習進度。

### OWN-WORLD

繼承目前課程的字型、色彩、按鈕與焦點樣式，以既有語意變數呈現狀態；不更換網站識別、不引入新字型、圖像、動畫或套件。

### STORY

使用者選擇正常或慢速，啟動有聲導讀，看到目前段落並跟讀；可重播當句與停止。切教材、切頁及頁籤隱藏時停止，錯誤時仍能閱讀並重試。

### FIRST VIEWPORT

保留目前導覽與教材。語音控制緊接主要原文／解說區，呈現播放導讀、原文示範、重播當句及停止；小型語速與跟讀選擇放在同一操作區，手機版換行且不擠壓教材。

### FORM

既有介面的局部功能擴充，Operate 模式；使用者已確認「課文講解＋發音跟讀」，不另作視覺方向抽選或重設計。

### FINISH

未完成審查與文件即未完成；本輪以功能與生命週期測試、桌面／手機實際驗收、獨立完成審查、既有設計對照及修訂紀錄收束。無新增出貨點陣素材，不建立或改寫全站設計系統。

## 共用介面

- `AudioLesson`：`lessonId`、`title?`、`segments: AudioLessonSegment[]`；每段有穩定 `id`、原文 `text`、正確 `lang`、`kind` 與可選 `audioSrc`。
- `startAudioLesson(segments, options)`：沿用 `speech.ts` 與既有音檔工具，回傳停止函式；選項與型別定義於 `audioLessonTypes.ts`。
- 段落完成依真正結束事件，不以 2.5 秒假定長句播完。停止必須取消待播、跟讀留白、舊回呼與目前聲音。
- 完整導讀依「原文示範 → 同組既有解說 → 留白跟讀」前進；單獨聽原文時直接在示範後留白。跟讀狀態回到該組原文，不把解說或錯誤選答當作跟讀內容。
- 臺灣華語語音接受 `zh-TW`、未指定其他地區的 `zh-Hant` 與 `zh-Hant-TW`；不以香港或中國地區聲音冒充臺灣華語。
- 解說使用各軌已本地化的支援文字；日語原文、英語原文、臺灣華語原文及拼音／注音不隨介面語言變動。
- 不在尚未作答時朗讀正確答案；不修改題目、XP、答題結果或完成度契約。

## 語音教學.2 的局部優化契約

繼承上列 Sam 所有、中立教學、Operate 模式及同一視覺風格，不更換作者、贊助者、教材、進度格式或發布權限。

- 播放範圍分為完整導讀、原文示範及當句重播；狀態分母採本次選取段數，完成訊息不能把單獨示範／當句重播稱為完整導讀完成。
- 已啟動的播放在停止、完成或錯誤後保留可見重播目標，標示原文示範／解說及語言；換教材或語系仍清除舊目標，不自動續播。
- `preparing` 表示等待啟動，不能宣稱已播放；TTS 收到正常原文的原生 `start`、音檔收到原生 `playing` 後才進入 `playing`。
- 未確認開始就結束，必須進入可重試失敗，不續播下一段或宣稱完成。10 秒啟動期限只判定未啟動，不當作結束事件；正常開始的長句仍依真正結束前進。
- 已開始卻遺失結束、原生狀態連續閒置時，收束成失敗並清理所屬資源；正在 speaking／pending 的長句不得因這個偵測被切斷。停止、世代更換及晚到回呼保持原有隔離契約。
- 音檔不能啟動時沿用原有 TTS 回退，不新增其他語音服務；兩種來源都無法啟動時明示失敗與重試方向。原生事件仍不等同人工可聽性、音質或發音評分驗收。

## 語音教學.3 的補完契約

- 音檔真正開始後，持續觀察其原生 `currentTime`；只有時間實際前進才重設停滯寬限。連續 10 秒沒有進度時停止並清理原音檔，再依同一原文、語言與語速回退 TTS。
- 這是「無進度期限」，不是整段播放時間上限；慢速、長音檔及短暫緩衝後恢復都不得被固定片長截斷。反覆 `playing` 不新增計時器或延長停滯期限。
- 結束、錯誤、停止、同步換播放者及晚到回呼維持所屬清理與互斥；不能在回退時讓舊音檔與 TTS 同時播放。
- 真正掛載驗收補上失敗重試、空聲音清單稍後恢復及跟讀期間切設定。明示驗收 fixture 可使用相符的既有「あ」音檔，不替代課文資料，也不作為新增課文錄音或人工聽辨證據。
- Sam 另授權完整本機品質閘門及明確清單的本機提交；不包含 push、合併、部署或發布。裝置聲音、連線型日語未開始及人工可聽性限制保持明示。
- 來源說明依既有 audioSrc 是否存在區分：有音檔的教材描述音檔及系統語音回退，不推論其為真人／合成；純 TTS 保留系統合成說明。兩者都保留非發音評分及裝置／連線限制，不因驗收 fixture 改寫正式教材。

## 語音教學.4 的素材與裝置補完契約

- 沿用既有 `orange:6` 三筆 passage、識別、原文、`speakText ?? sentence` 與 `audio.src`，只補上原本缺少的三個 MP3，更新其實測 `durationMs` 及真實合成聲音名稱。不能以假名單音替代英語課文，不新增平行教材來源。
- 新素材明示本機 Windows `Microsoft David Desktop`、`en-US` 系統合成、非真人錄音；檔內 ID3、來源原文雜湊、音檔雜湊、README 與純 Node.js 測試必須互相一致。產音腳本不得覆寫既有音檔、刪除證據或自動安裝依賴。
- 音檔來源載入會重設 `playbackRate` 為 `defaultPlaybackRate`；兩者須使用同一教學語速。正常 0.95、慢速 0.7 及原有 `SpeakButton` 1 倍速都沿用同一播放器，不另建慢速播放管線。
- 日語聲音從目前原生清單中優先選 `localService === true` 的日語聲音；沒有本機日語才沿用既有其他日語聲音。保留原英文選聲、臺灣華語地域限制、聲音清單更新及未開始失敗契約，不宣稱遠端聲音一定可用。
- Sam 授權納入 Windows 官方日語語音套件；目前安裝及安裝後原生播放仍待完成。聲音選擇測試通過不等於官方套件已安裝，不能以 registry、測試替身或舊日語事件單獨代替新的實機驗收。
- 本輪仍只作本機程式／素材提交，不推送、合併、部署或新增雲端供應商。原生事件與全檔解碼不等於人工聽辨、音質、逐字正確性或發音評分驗收。
