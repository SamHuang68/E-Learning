    Semantic radar needs more MAP space.

    SYN Synchronization

    • • Random Initial Sequence Number (ISN) protects against packet collision from prior dead connections
    • • Window Scaling and SACK options negotiate optimal link capacity

    Half-Close Semantics

    • • Active close sends FIN indicating it has no more data to write, but can still read
    • • Server acknowledges FIN and transitions to CLOSE_WAIT to flush remaining buffer

    TIME_WAIT & 2MSL Role

    • • Active close lingers in TIME_WAIT for 2 Maximum Segment Lifetimes (60~120s)
    • • Guarantees final ACK arrives safely and eliminates wandering ghost packets
